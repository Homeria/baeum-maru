# 메인 화면 껍데기와 목록·서랍 4개 탭 개편 (#118)

로그인 뒤 메인 화면을 왼쪽 메뉴(접기·열기 지원)와 하단 알림 띠 구조로 바꾸고, 회원·강좌·기초 정보·직원 관리 4개 탭을 전체 폭 표와 오른쪽 편집 서랍 구조로 개편했다.

- 관련: ADR 0023, BR-K3(역할별 권한), BR-K6(직원 사용 중지), BR-K10(PIN 새로 정하기), BR-K13(접속 기록), BR-K15·K16(기기 승인·취소), BR-H1(호스트 넘기기), BR-S10·S11(우선 배정 사유), BR-T4(수업 시간). 화면은 왼쪽 메뉴의 "수강 사무"(회원·신청·추첨·선발 결과)와 "기관 운영"(강좌·기초 정보·직원 관리), 각 탭의 목록 표·오른쪽 편집 서랍·확인 대화상자.
- 사용자 흐름
  1. 직원이 로그인하면 왼쪽에 업무 메뉴와 호스트 연결 상태, 하단에 로그인한 직원 이름·[화면 잠금]·[로그아웃]이 보인다. 필요하면 상단의 메뉴 접기 아이콘 버튼으로 본문을 전체 폭으로 넓힐 수 있다.
  2. 회원·강좌·기초 정보·직원 목록은 전체 폭 표로 보고, 오른쪽 위 등록 버튼이나 각 줄 클릭·[고치기] 버튼으로 오른쪽 편집 서랍을 연다.
  3. 서랍에서 값을 고친 채 닫기·[그만두기]·Esc·바깥 클릭을 누르면 "저장하지 않은 내용이 있습니다" 확인 창이 뜬다.
  4. 삭제·복원·기기 승인 취소처럼 되돌리기 어려운 동작은 모달 확인 대화상자를 거치고, [호스트 넘기기]는 백업 목록과 떨어진 별도 위험 카드에 둔다.
  5. 호스트 연결 끊김·새 기기 승인 요청·백업 실패는 화면 아래 알림 띠에 뜨며, [확인하기]를 누르면 해당 직원 관리 하위 탭(기기·백업)으로 바로 이동한다.
- 알아둘 점
  - 핵심 3개 업무 탭(신청·추첨·선발 결과)의 레이아웃 개편은 다음 PR에서 진행한다.
  - 1920×1080 같은 큰 화면의 글자·여백 비율 조정은 전체 탭 개편을 마친 뒤 별도 PR에서 한꺼번에 손본다.
  - 수정 권한이 없는 역할(예: 조회 전용, 우선 배정 사유 탭의 일반 직원)에게는 등록·고치기 버튼과 줄 클릭을 숨긴다.
- 웹페이지 안내: 주요 화면 흐름이 왼쪽 메뉴와 목록·편집 서랍 구조로 바뀌었으므로 전체 화면 개편(신청·추첨·선발 결과 포함)이 끝난 뒤 사용 안내 문구와 스크린샷을 한꺼번에 갱신한다.

## 목록과 입력 화면을 어떻게 배치하나

- 후보
  - 왼쪽 목록과 오른쪽 고정 입력 칸을 나란히 둔다(기존 방식)
  - 전체 폭 목록 표를 두고 등록·고치기만 오른쪽 모달 서랍으로 연다
- 고른 것: 전체 폭 목록 표 + 오른쪽 편집 서랍
- 이유: 회원 연락처·생년월일, 강좌의 여러 요일 수업 시간과 강의실, 직원의 역할·유효기간·상태가 한 줄에 넉넉히 들어간다. 기존 2단 분할에서는 좁은 창(1280×680)에서 표가 좁아지고, 조회 전용 역할에서도 오른쪽 칸이 빈 안내로 자리를 차지했다. (원리만)

## 서랍에서 고치던 내용을 실수로 닫으면 어떻게 하나

- 후보
  - 닫기나 바깥 클릭 시 바로 닫는다
  - 바꾼 내용이 있을 때만 닫기 확인 창을 띄운다
- 고른 것: 바꾼 내용이 있을 때만 닫기 확인 창을 띄운다
- 이유: 보기만 하고 닫을 때는 한 번에 닫혀 빠르고, 입력 도중 실수로 Esc나 바깥 영역·[그만두기]를 눌러도 내용이 바로 사라지지 않는다. 확인 창의 첫 초점은 안전한 [계속 편집] 버튼에 둔다. (테스트로 확인)

## 호스트 연결 끊김·기기 승인 요청·백업 실패를 어디에 알리나

- 후보
  - 화면 맨 위 머리줄 아래에 막대를 여러 줄 쌓는다
  - 화면 아래쪽 고정 알림 띠(최대 3줄)에 모으고 바로가기 버튼을 둔다
- 고른 것: 화면 아래쪽 알림 띠
- 이유: 위쪽 막대가 늘어나면 작업 중인 표가 아래로 밀려 클릭 위치가 흔들린다. 아래쪽 알림 띠는 본문 높이를 밀어내지 않으면서 긴급 오류(`role="alert"`)와 일반 안내(`role="status"`)를 구분해 알리고, [확인하기] 한 번으로 백업·기기 탭으로 이동할 수 있다. (테스트로 확인)

## 백업 탭에서 [호스트 넘기기]를 어디에 두나

- 후보
  - [지금 백업]·[복원] 버튼 옆에 나란히 둔다
  - 백업 목록·두 번째 위치 카드와 떨어뜨린 별도 위험 영역 카드에 둔다
- 고른 것: 별도 위험 영역 카드
- 이유: [지금 백업]은 평소 자주 누르는 버튼이고, [호스트 넘기기]는 서버를 끄고 PC를 바꿀 때만 쓰는 위험한 동작이다. 나란히 두면 실수로 누르기 쉬워 별도 빨간 테두리 카드로 떼어 내고, 눌렀을 때도 PIN 확인 모달을 거치게 했다. (테스트로 확인)

## 강좌 목록에서 여러 요일·시간대 수업을 어떻게 보여 주나

- 후보
  - 쉼표로 한 줄에 이어 쓴다
  - 요일·시간대 묶음마다 셀 안에서 줄을 바꾼다
- 고른 것: 셀 안에서 줄바꿈
- 이유: "월·수 10:00~11:00, 금 14:00~15:00"처럼 시간대가 두 줄 이상인 강좌는 쉼표로 이어 쓰면 가로로 길어지거나 어중간한 곳에서 끊겨 읽기 어렵다. 묶음마다 줄을 나누어 한눈에 시간표를 파악할 수 있게 했다. (테스트로 확인)
