# 선택 기록

기능을 만들며 고른 것을 남긴다. 무엇을 정해야 했는지, 후보가 무엇이었는지, 왜 그것을 골랐는지만 적는다.

- ADR과 다르다. ADR은 프로젝트 전체가 따르는 기반 결정이고, 바꾸려면 새 ADR이 필요하다. 선택 기록은 기능 하나 안에서 고른 것이고, 나중에 바뀌어도 기록을 고치지 않는다.
- 기술 블로그의 글감으로 쓴다. 여기서는 사실과 이유만 적고, 읽는 사람에 맞게 풀어 쓰는 일은 블로그에서 한다.
- 파일 하나가 이슈 하나다. 이름은 `<이슈 번호 네 자리>-<브랜치의 하는 일>.md`다 (예: `0054-broken-db-restore.md`).
- 실제 기관 이름과 회원 정보는 쓰지 않는다.

## 형식

```markdown
# 제목 (#이슈 번호)

무엇을 만들었는지 한두 문장.

## 정해야 했던 것

- 후보: A, B, C
- 고른 것: B
- 이유: 짧게. 버린 후보의 문제도 한 줄.
```
