# 실행 모드 바꾸기의 관리자·PIN 칸을 넘기기와 같게 (#104)

화면 코드를 정리하며 실행 모드 바꾸기 대화상자가 넘기기 화면의 관리자·PIN 칸 부품을 함께 쓰게 했다. 그 결과 이 대화상자의 동작이 넘기기 화면과 같아졌다.

- 관련: BR-K17, ADR 0021, 화면 "이 PC를 호스트로 바꿀까요?", "이 PC를 다른 PC에 접속하는 모드로 바꿀까요?"
- 사용자 흐름: 실행 모드 바꾸기 → (지킬 데이터가 있으면) 관리자를 고르고 PIN 넣기 → "바꾸고 다시 켜기"
- 알아둘 점: 문구, 칸 이름, 비운 채 눌렀을 때의 안내는 그대로다
- 웹페이지 안내: 없음

## 정해야 했던 것

- 후보: 넘기기 화면과 같은 부품으로 맞추기, 부품만 옮기고 대화상자는 그대로 두기
- 고른 것: 넘기기 화면과 같게 맞추기
- 이유: 같은 관리자 PIN 확인이 화면마다 다르게 보이지 않게 한다. 바뀌는 것은 셋이다. 관리자 목록이 오기 전에는 PIN 칸을 보이지 않는다. 쓸 수 있는 관리자가 없으면 빈 칸 대신 "쓸 수 있는 관리자 계정이 없습니다"를 보인다. 비운 채 누르면 화면 읽기 프로그램도 PIN 칸이 틀렸다고 읽는다(원리만). 그대로 두면 같은 칸을 두 곳에서 따로 고쳐야 한다.
