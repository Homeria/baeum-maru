# 신청·추첨·선발 결과 핵심 3개 탭 개편 (#120)

수강 사무의 핵심 3개 탭(신청·추첨·선발 결과)과 규칙 예외·신청 삭제·연락 결과·포기·바로잡기·결과 명단 내보내기 대화상자를 공통 부품과 새 배치로 개편했다.

- 관련: ADR 0016(추첨), ADR 0018(결과 명단 내보내기), ADR 0023, BR-A4~A7(신청 규칙·예외), BR-D1~D3(신청 삭제), BR-L3~L6(추첨·마감), BR-S4~S7·S12~S15(우선 배정), BR-W1~W8(대기자 연락·포기·바로잡기), BR-X1~X2(추가 신청), BR-P1~P10(결과 명단). 화면은 `신청`, `추첨`, `선발 결과` 탭.
- 사용자 흐름
  1. `신청` 탭: 왼쪽에서 회원을 찾아 고르면 그 회원의 기존 신청이 아래 카드에 뜨고, 오른쪽 강좌 표에서 여러 강좌를 체크해 [N건 신청하기]를 누른다. 규칙을 어기면 예외 사유 창이 뜨고, 마감 강좌는 추가 신청 결과(바로 당첨 / 대기 N번째)를 꼬리표로 미리 본다.
  2. `추첨` 탭: 강좌를 고르면 강좌명 제목 아래 신청자·당첨자·대기자 3칸 카드가 나온다. [시작]을 누르면 신청자 목록은 고정된 채 당첨자·대기자 칸이 0.05초마다 섞이고(자리 보장 신청은 당첨자 맨 위에 고정), [멈춤]을 누르면 호스트가 확정한 결과로 고정된다. 이후 [선발 마감]이나 [다시 추첨]을 모달 확인 뒤 실행한다.
  3. `선발 결과` 탭: 왼쪽 세로 목록에서 마감 강좌를 고르면 오른쪽에 회원 찾기, 파란 머리줄의 당첨자, 가장 넓은 대기자(노란 `연락할 차례` 강조), 포기 3칸이 나온다. 당첨자는 [포기], 대기자는 [연락·포기], 포기는 [바로잡기] 모달로 기록하고, 위쪽 [결과 명단 내보내기]로 Excel 파일을 저장한다.
- 알아둘 점
  - 추첨 섞기 모션은 화면에서 진행 상태를 보여 주는 연출일 뿐, 최종 순서는 [멈춤]을 누른 순간 호스트가 정한다(ADR 0016).
  - 조회 전용 역할에게는 신청 막대·지우기·추첨·포기·연락 결과·바로잡기 버튼과 원본 명단 선택지를 숨긴다.
  - 1920×1080 같은 큰 화면의 글자·여백 비율과 구버전 부품 파일 정리는 전체 탭 개편 이후 별도 PR에서 다룬다.
- 웹페이지 안내: 신청·추첨·선발 결과 화면이 새 카드·표·대화상자 구조로 개편되었으므로 첫 실행 안내(PR 7)와 화면 크기 마무리(PR 8) 뒤에 전체 사용 안내 문구와 스크린샷을 한꺼번에 갱신한다.

## 추첨 섞기 모션을 어느 칸에 두고 얼마나 빠르게 돌리나

- 후보
  - 신청자 칸을 0.25초마다 섞고 당첨자·대기자 칸은 비워 둔다(기존 방식)
  - 신청자 칸은 고정하고 당첨자·대기자 칸을 0.05초마다 섞어 보여 준다
- 고른 것: 신청자 고정 + 당첨자·대기자 0.05초 섞기
- 이유: 현장에서 화면을 함께 보는 회원은 자기 이름이 신청자 목록에 있는지 확인하면서, 동시에 당첨자·대기자 자리가 빠르게 돌아가는 모습을 볼 때 추첨이 진행 중임을 직관적으로 느낀다. 기존 0.25초는 화면이 느리게 끊겨 보였다. 자리 보장 신청은 섞는 동안에도 당첨자 맨 위에 고정해 혼동을 막았다. (직접 확인, 테스트로 확인)

## 선발 결과의 `연락할 차례` 강조와 대기자 처리 버튼을 어떻게 구성하나

- 후보
  - 당첨자·대기자·포기 3칸을 같은 폭(1:1:1)으로 두고 대기자 줄에 [연락 결과]·[포기] 버튼 2개를 나란히 둔다
  - 대기자 칸을 가장 넓게(1:1.45:0.9) 두고 노란 바탕(`연락할 차례` 전용)과 [연락·포기] 버튼 1개만 두되, 모달 안에서 "승격 연락 결과"(수락·거절·연락 안 됨)와 "본인 요청 포기"(사유 선택)를 구역으로 나눈다
- 고른 것: 넓은 대기자 칸 + 노란 `연락할 차례` 전용 강조 + [연락·포기] 단일 버튼과 2구역 모달
- 이유: 대기자 줄에는 순번·이름·연락처·연락 상태가 한꺼번에 들어가고, 바깥에 [포기]를 따로 두면 모달 안의 "거절"(포기 전환)과 중복처럼 보여 헷갈린다. 줄에는 [연락·포기] 1개만 두어 오클릭을 막고, 모달 안에서 승격 연락 거절(BR-W2·W4)과 연락 전 본인 취소(BR-C3)를 명확히 나누어 서버의 두 기록 경로를 모두 보존했다. (직접 확인, 테스트로 확인)

## 신청 탭 강좌 표의 여러 요일 시간과 추가 신청 미리보기를 어떻게 보여 주나

- 후보
  - 수업 시간을 쉼표로 한 줄에 이어 쓰고, 추가 신청 결과를 회색 보조 글자로 붙인다
  - 수업 시간을 셀 안에서 줄바꿈하고, 추가 신청 결과를 꼬리표(`바로 당첨` 초록 / `대기 N번째` 회색)로 표시한다
- 고른 것: 셀 안 줄바꿈 + 상태 꼬리표
- 이유: 강좌 탭과 같은 방식으로 시간표를 줄바꿈해 가독성을 맞췄고, 마감 강좌에 추가 신청할 때 바로 당첨되는지 대기로 들어가는지 접수 직원이 한눈에 구분할 수 있게 했다. (테스트로 확인)
