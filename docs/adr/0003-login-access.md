# 0003. 로그인: 기기 승인(요청형) + 직원 PIN

- 상태: 채택 (2026-11-14)
- 근거: [0001](0001-app-form.md), [0002](0002-data-owner.md)

## 상황

호스트 PC의 서버는 같은 네트워크의 기기가 접속할 수 있다 (0001의 웹 예비 포함). 대상 기관에서 현실적인 위험은 이렇다.

- **이용자와 같은 Wi-Fi**: 복지관, 문화센터는 이용자용 Wi-Fi를 열어 두는 곳이 많다. 주소(예: `192.168.0.12:47800`)만 알면 회원 명단에 들어올 수 있다.
- **자리를 비운 PC**: 접수처 PC는 이용자 바로 앞에 있다.
- **누가 했는지**: 추첨 실행, 규칙 예외, 신청 삭제 같은 기록에 처리한 직원이 남아야 한다 ([업무 규칙](../domain/BUSINESS_RULES.md)).

이전 버전에서는 서버가 역할별 접속 코드(`XXXX-XXXX`)를 미리 발급하고, 역할마다 로그인 가능 시간을 두었다.

## 선택지

**기기를 어떻게 들일지**
1. **요청형**: 새 기기가 접속을 요청하면 호스트 화면에 일회용 번호가 뜨고, 그 번호를 새 기기에 입력하거나 호스트에서 허용한다.
2. **요청형 + 발급형**: 위에 더해 관리자가 일회용 기기 등록 코드를 미리 발급할 수 있다.
3. **발급형**: 관리자가 미리 발급한 코드로 등록한다 (이전 방식에 가까움).

**사람을 어떻게 구분할지**
- 역할별 공용 코드 / 직원 개인 계정

## 결정

**첫 버전에 로그인을 넣는다. 두 겹으로 한다.**

1. **기기 승인 (요청형)**
   - 승인받지 않은 기기는 아무 화면도 볼 수 없다.
   - 새 기기가 요청하면 호스트 화면에 요청한 기기와 일회용 번호가 뜬다. 번호는 몇 분 안에만 유효하다.
   - 앱이 깔린 PC는 한 번 승인하면 계속 기억한다. 브라우저 접속은 그날만 유효하다.
   - 관리자는 승인한 기기 목록을 보고 승인을 취소할 수 있다.
2. **직원 확인 (이름 + PIN)**
   - 직원마다 계정이 있다. 승인된 기기에서 이름을 고르고 숫자 PIN을 입력한다.
   - 역할: 관리자 / 직원 / 임시 직원 / 조회 전용
   - 계정에 유효기간을 둘 수 있다. 임시 직원(사회복무요원, 자원봉사자)은 접수 기간이 끝나면 저절로 막힌다.
   - 일정 시간 입력이 없으면 화면이 잠기고, PIN으로 다시 연다.
   - PIN을 여러 번 틀리면 그 계정을 잠시 잠근다.
3. **처음 설치할 때**: 관리자 계정 하나와, PIN을 잊었을 때 쓰는 복구 코드를 만들고 인쇄하도록 안내한다.
4. **접속 기록**: 누가, 언제, 어느 기기에서 로그인했는지 남긴다.

자동 잠금 시간, 허용 실패 횟수 같은 구체적인 값은 기능을 만들 때(6단계) 정한다.

## 이유

- 기기 승인이 "주소만 알면 들어온다"는 문제를 막는다. 일회용 번호라 새어도 몇 분 뒤면 쓸모없다.
- 직원 PIN과 자동 잠금이 "자리 비운 PC"와 "누가 했는지" 문제를 막는다.
- 대상 기관은 PC 2~4대가 한 사무실에 있는 경우가 많아, 처음 한 번 호스트 앞에서 승인하는 불편은 작다.
- PIN은 짧아서 임시 직원도 쓰기 쉽다. 승인된 기기에서만 시도할 수 있고 여러 번 틀리면 잠기므로, 짧아도 버틸 만하다.
- 이전 방식의 좋은 점(임시 인원에게 기간 한정 권한)은 계정 유효기간으로 살렸다.

## 결과

**좋은 점**
- 이용자 Wi-Fi, 자리 비움, 기록 남기기 문제를 첫 버전부터 다룬다.
- 기록마다 사람 단위로 "누가 했는지"가 남는다.

**감수할 점**
- 호스트 PC 앞에 누군가 있어야 새 기기를 들일 수 있다.
- 직원 계정 관리(추가, 유효기간, PIN 초기화)가 관리자 일로 생긴다.

**나중에 할 것 (7단계 보안 고도화)**
- **암호화 통신(TLS)**: 지금은 같은 Wi-Fi에서 오가는 내용(PIN 포함)을 엿볼 수 있다.
- 역할별 로그인 가능 시간대 (예: 임시 직원은 평일 9~18시)
- 발급형 기기 등록 코드 (호스트 PC가 다른 방에 있는 기관용)
- 그 밖의 웹 보안 항목 (CSRF 등)
