# 0021. 실행 모드: 처음 한 번 고르고 기억, 관리자 PIN으로 바꾼다

- 상태: 채택 (2026-11-24)
- 근거: [0001](0001-app-form.md), [0002](0002-data-owner.md), [0003](0003-login-access.md), [0004](0004-host-discovery.md), [0007](0007-app-only-access.md)

## 상황

모든 직원 PC에 같은 앱을 깔고, 어느 PC든 호스트가 될 수 있다(0001). DB는 호스트 한 대에만 있다(0002). 접속하는 앱은 호스트 주소를 한 번 입력받아 기억한다(0004).

그런데 앱이 켜질 때 호스트로 켤지, 다른 PC에 접속할지 정하는 방법은 정하지 않았다. 지금 앱은 켜면 늘 자기 PC의 DB를 여는 호스트로만 동작한다.

게임의 "서버 열기 / 들어가기"처럼 켤 때마다 고르게 하면 이해하기는 쉽다. 하지만 직원이 잘못 누르면 그 PC에 빈 DB가 하나 더 생긴다. 그 PC로 받은 신청은 진짜 호스트에 들어가지 않고, 명단이 둘로 갈라진다.

## 선택지

**모드를 언제 고를지**
1. **처음 한 번 고르고 기억**: 바꾸는 것은 설정 안쪽에서 한다.
2. **켤 때마다 고르기**
3. **처음 한 번 고르고 기억하되, 시작 화면에 "모드 바꾸기"를 둔다**

**호스트에 닿지 않을 때**
1. 안내하고 다시 시도하게 한다.
2. 위에 더해 "이 PC를 호스트로 쓰기"를 제안한다.

## 결정

**모드는 3번, 호스트에 닿지 않을 때는 1번.**

- 앱의 **실행 모드**는 호스트와 접속 둘이다. 처음 켤 때 "이 PC에서 새로 시작(호스트)"과 "다른 PC에 접속" 중 하나를 고르고, 데이터 폴더에 기억한다. 다음부터는 묻지 않는다.
- 이미 DB가 있는 PC는 묻지 않고 호스트로 켠다. 지금까지 쓰던 PC가 업데이트 뒤에 질문을 받지 않게 하기 위해서다.
- 시작 화면에 "모드 바꾸기"를 둔다. 관리자 이름과 PIN을 확인해야 바뀐다. 접속 모드 PC에는 직원 계정이 없으므로 호스트에 물어 확인한다.
- 호스트였던 PC를 접속 모드로 바꿔도 그 PC의 DB는 지우지 않고 쓰지 않는다. 다시 호스트로 바꾸면 그 DB로 돌아온다. 접속 모드 화면에 "이 PC에 이전 데이터가 남아 있습니다"를 알린다.
- 접속 모드에서 호스트에 닿지 않으면 "호스트 PC가 꺼져 있거나 주소가 바뀌었을 수 있습니다"와 [다시 시도], [주소 다시 입력]만 보여 준다. 이 PC를 대신 호스트로 쓰는 길은 열지 않는다.
- 접속 모드에서는 DB를 열지 않고, 서버와 자동 백업도 켜지 않는다.

## 이유

- 기관에는 호스트가 한 대여야 한다(0002). 모드를 고르는 순간을 처음 한 번으로 줄이고 바꾸기에 관리자 PIN을 걸면, 직원의 실수로 DB가 갈라지는 일을 막는다.
- 시작 화면의 버튼은 관리자가 설정까지 들어가지 않고도 바꿀 수 있게 한다. 대신 PIN으로 막는다.
- 남은 DB를 지우지 않으면 잘못 바꿨을 때 되돌릴 수 있다. 개인정보가 든 파일을 앱이 몰래 지우지도 않는다.
- 호스트가 꺼진 것은 대개 잠깐이다. 그때 다른 PC가 호스트가 되면 데이터가 갈라지는 피해가 더 크다.

## 결과

**좋은 점**
- 직원은 처음 한 번만 고른다. 그 뒤로는 켜면 바로 쓴다.
- 기존 사용자는 아무것도 바뀌지 않는다.

**감수할 점**
- 호스트 PC가 고장 나면 접속 모드 PC를 호스트로 바꿀 수 없다. PIN을 확인할 호스트가 없기 때문이다. 호스트 넘기기와 백업으로 새로 시작하기를 따로 만든다.
- 옛 호스트의 DB가 남아 있어서, 그 PC를 다시 호스트로 켜면 호스트가 둘이 될 수 있다. 0002와 0004의 데이터 묶음 ID·세대 번호 확인으로 막고, 호스트 넘기기와 함께 만든다.
