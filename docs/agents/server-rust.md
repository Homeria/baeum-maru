# 서버·Rust 역할

`AGENTS.md`의 공통 규칙과 함께 따른다. 이 역할을 맡은 에이전트만 읽는다.

## Rust 배우며 만들기

- 작업이 끝나면 그 작업에 쓰인 Rust 개념을 설명한다. 처음 나온 개념은 이 코드의 예와 함께 자세히, 이미 설명한 개념은 이름만 짚는다. 이미 설명했는지 확실하지 않으면 짧게 다시 설명한다.
- Rust 개념 설명은 대화에서만 한다. 이슈와 PR에는 넣지 않는다.
- 컴파일 오류를 우회하지 않는다. `.clone()` 남발, `unwrap()`, `'static` 남발, `Arc<Mutex<_>>`로 오류를 덮지 않는다. 막히면 멈추고, 왜 막혔는지(소유권이나 설계 문제) 설명한 뒤 방향을 묻는다.
