# 배움마루

**교육 프로그램의 신청, 선발, 명단 정리까지 기관의 수강 사무 전반을 처리하는 무료 프로그램.**

노인문화센터, 노인복지관, 주민자치센터, 작은 복지관·문화원처럼 **직원이 신청을 직접 받아 처리하는 소규모 교육·여가 프로그램 운영 기관**을 위한 프로그램입니다.

## 왜 만드나요

많은 기관이 수강 신청과 추첨을 종이와 엑셀로 처리하거나, 유료 프로그램을 구입해서 씁니다.

- 신청서를 엑셀로 옮기고 합치는 과정에서 중복 신청, 정원 계산 실수, 시간이 겹치는 신청이 생깁니다.
- 추첨, 대기자 순번, 결과 명단을 손으로 정리하는 데 많은 시간이 듭니다.
- 이런 일을 돕는 프로그램은 대부분 유료라, 예산이 적은 기관일수록 쓰기 어렵습니다.

배움마루는 이 일을 **누구나 무료로** 할 수 있게 만드는 것을 목표로 합니다.

## 누구를 위한 프로그램인가요

- **대상 기관**: 이용자가 방문해서 신청하는 소규모 교육·여가 프로그램 운영 기관 (노인문화센터, 노인복지관, 주민자치센터, 작은 복지관·문화원 등)
- **사용자**: 신청을 접수하고 명단을 관리하는 기관 직원 (IT 담당자가 없어도 쓸 수 있어야 합니다)
- **신청 방식**: 직원이 현장·전화로 받은 신청을 대신 입력합니다. 기관 안의 여러 직원이 동시에 함께 사용할 수 있습니다.

기관마다 받는 정보, 신청 개수 제한, 선발 방식이 다르기 때문에, 기관이 자기 방식에 맞게 설정해서 쓸 수 있도록 만듭니다.

## 하지 않는 것

- 신청자가 직접 입력하는 온라인 신청
- 학교 방과후학교처럼 이미 전용 시스템이 있는 기관을 위한 기능
- 결제·수납, 문자·알림 발송, 회계, 강사 급여, 온라인 강의

데이터는 기관 안에만 보관합니다. 외부 클라우드 저장은 나중에 검토할 수 있습니다.

## 현재 상태

개발을 시작하는 단계입니다. 아직 사용할 수 있는 버전은 없습니다.

- **버그 제보와 기능 제안**은 이슈로 환영합니다.
- 코드 기여 방식은 아직 정하지 않았습니다.
- 이슈에 실제 이용자의 개인정보(이름, 연락처, 생년월일 등)를 올리지 마세요.
