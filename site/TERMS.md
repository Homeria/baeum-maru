# 쉬운 말 대응표

웹페이지와 블로그에서 기술 용어를 기관 직원이 이해하기 쉬운 말로 바꿔 쓸 때 참고하는 표다.

- 업무 용어(회원, 강좌, 당첨, 자리 보장 등)는 [용어집](../docs/domain/GLOSSARY.md)의 말을 그대로 쓴다.
- 배포 용어(설치판, 포터블판, 서명, 업데이트)는 용어집 "배포" 절의 말을 쓰고, 처음 나올 때 괄호 풀이를 붙인다.
- 아래 기술 용어는 본문에서 되도록 오른쪽 쉬운 말을 쓴다.

| 기술·개발 용어            | 웹페이지·블로그에서 쓰는 쉬운 말           | 비고                                               |
| ------------------------- | ------------------------------------------ | -------------------------------------------------- |
| DB, 데이터베이스          | 데이터 파일                                | 회원·신청 정보가 담긴 파일                         |
| SQLite                    | (쓰지 않음)                                | 필요하면 "프로그램 안의 데이터 파일"로 설명        |
| 호스트 PC                 | 데이터를 보관하는 대표 PC (또는 호스트 PC) | 앱 화면에 "호스트"가 나오므로 첫 표기에 풀어 설명  |
| 로컬, 로컬 저장           | 기관 PC 안에만 저장                        | 외부 서버로 보내지 않는다는 뜻을 함께 설명         |
| LAN, 같은 네트워크        | 기관 안의 같은 인터넷(공유기)에 연결된 PC  | 다른 PC 접속 안내 시 사용                          |
| 릴리스, GitHub 릴리스     | 공식 다운로드 페이지 (또는 새 버전 배포)   | GitHub 링크임을 밝힐 때만 "GitHub" 병기            |
| 마이그레이션, 스키마 변경 | 데이터 형식 업데이트                       | 앱 버전을 올릴 때 데이터 파일이 바뀌는 상황        |
| 오픈소스, MIT 라이선스    | 누구나 무료로 쓸 수 있는 공개 프로그램     | 소개 페이지에서만 "MIT 라이선스" 한 번 병기        |
| WebView2                  | Windows 화면 실행 구성요소                 | 설치판이 함께 설치해 준다는 맥락에서만 간단히 언급 |
| SmartScreen               | Windows 보안 경고 창                       | 처음 실행할 때 뜰 수 있는 파란 경고 창             |
| 방화벽 허용               | Windows 방화벽 허용 창                     | 다른 PC 접속을 위해 허용을 누르는 창               |
| 백업 복원                 | 이전 백업으로 되돌리기                     | 앱 화면 버튼 이름("되돌리기")과 맞춤               |
| 로그, 앱 로그             | 오류 기록 파일                             | 개인정보는 적지 않는다는 설명에 사용               |
